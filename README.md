## 🛍 Магазин PvP-титулов

Токены из `/daily_claim` теперь можно тратить на сезонные косметические титулы.
Они не дают игровых преимуществ и не влияют на Elo, судейство или подбор соперника.

| ID | Титул | Цена | Требуется очков |
|---|---|---:|---:|
| `first_word` | 🗣️ Первое слово | 60 🪙 | 0 ⭐ |
| `sharp_reply` | ⚡ Острое опровержение | 120 🪙 | 100 ⭐ |
| `cold_logic` | 🧠 Хладнокровный логик | 180 🪙 | 250 ⭐ |
| `tactical_speaker` | ♟️ Тактический оратор | 260 🪙 | 450 ⭐ |
| `argument_master` | 🏛️ Мастер аргумента | 360 🪙 | 700 ⭐ |
| `season_legend` | 👑 Легенда сезона | 500 🪙 | 1000 ⭐ |

```text
/shop                  каталог, цены и состояние разблокировки
/buy sharp_reply       купить титул
/inventory             показать купленные титулы
/equip sharp_reply     выбрать активный титул
/equip none            снять активный титул
```

Первая покупка автоматически экипируется. Повторная `/buy` для уже купленного титула
не списывает токены. Покупки и экипировка привязаны к текущему `PVP_SEASON`.

## 🎯 Ежедневные задания

Каждый progression-день бот детерминированно выбирает три задания из каталога:

- завершить один или два PvP-матча;
- победить в PvP;
- завершить два рейтинговых матча;
- сыграть с двумя разными соперниками;
- победить в рейтинговом матче.

```text
/daily        показать задания, прогресс и награды
/daily_claim  получить все завершённые неполученные награды
```

Повторный `/daily_claim` не начисляет награду второй раз. Уникальный ключ claim:
`user_id + season + day + quest_id`.

## 🏅 Сезонный прогресс

Сезонные очки существуют отдельно от Elo и открывают доступ к косметике.

| Уровень | Название | Минимум очков |
|---:|---|---:|
| 1 | Новичок | 0 |
| 2 | Спорщик | 100 |
| 3 | Оратор | 250 |
| 4 | Тактик | 450 |
| 5 | Мастер аргумента | 700 |
| 6 | Легенда сезона | 1000 |

```text
/season      токены, очки, уровень, серии и активный титул
/season_top  топ-10 по очкам текущего сезона
```

## 📊 PvP-аналитика

Команда `/pvp_stats` показывает:

- текущий Elo и место в сезоне;
- рейтинговые и нерейтинговые матчи отдельно;
- победы, ничьи, поражения и win rate;
- число уникальных соперников;
- изменение Elo за настраиваемое окно;
- текущую и лучшую серии побед;
- результаты за стороны «за» и «против».

## 🧠 Надёжность покупок

- профиль пользователя блокируется перед изменением кошелька;
- баланс, право владения и экипировка меняются одной транзакцией;
- составной primary key исключает повторную покупку;
- закрытая или слишком дорогая покупка не изменяет баланс;
- каталог хранится в коде и не требует внешнего API;
- косметика не изменяет Elo, исход матча или награды заданий.

## 🗄️ Хранилища

### PostgreSQL

Постоянно хранятся профили, архивы, PvP Elo, завершённые матчи, blocklist,
жалобы, progression wallets, daily claims, покупки титулов и текущая экипировка.

### Redis

Временно хранятся активные споры, PvP-матчи, приглашения, очередь, дедлайны,
request locks, rate limit и подтверждение удаления данных.

## ⚙️ Переменные progression

```env
PVP_DAILY_RESET_HOUR_UTC=0
PVP_DAILY_REWARD_MULTIPLIER=1
PVP_STATS_WINDOW_DAYS=30
```

Ограничения:

- reset hour: `0..23`;
- reward multiplier: `1..10`;
- analytics window: `1..365` дней.

Каталог v0.8 не требует новых переменных окружения.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/DisputesBot.git
cd DisputesBot
cp .env.example .env
```

Заполните `BOT_TOKEN`, `OPENAI_API_KEY` и при необходимости `MODERATOR_USER_IDS`.

```bash
docker compose up -d postgres redis
pip install -e ".[dev]"
alembic upgrade head
python -m bot.main
```

Полный запуск в Docker:

```bash
docker compose up --build -d
```
