## 🗂 Карьера и сезонный архив

### Личная PvP-карьера

```text
/pvp_career
```

Команда показывает:

- число сезонов и матчей;
- общий рекорд и процент побед;
- карьерный максимум Elo;
- лучший сезон по итоговому рейтингу;
- итоговый и пиковый Elo каждого сезона;
- изменение Elo относительно первого сохранённого матча;
- итоговое место и дивизион.

Пиковый Elo восстанавливается из сохранённых значений рейтинга до и после каждого
матча. Отдельный карьерный профиль не создаётся.

### Архив таблиц

```text
/season_archive
/season_archive season-1
```

Без аргумента команда выводит доступные сезоны, число игроков и матчей. С аргументом
показывается топ-10 выбранного сезона. Для активного сезона отображается текущее
состояние таблицы, для завершённого — последнее сохранённое состояние.

### Hall of Fame

```text
/hall_of_fame
```

Зал славы показывает лидера каждого сезона. Чемпион определяется теми же стабильными
правилами, что и обычный leaderboard: Elo, число матчей, время обновления и user ID.

Архивные команды не читают стенограммы, аргументы или оценки судьи. Они используют
только сезон, публичное отображаемое имя, Elo и агрегированную статистику матчей.

## 🎓 Приватный PvP coaching

```text
/match_review
/match_review 0123456789abcdef
/pvp_coach
```

`/match_review` показывает приватный разбор собственного полного матча: результат,
позицию, Elo-дельту, оценки логики, доказательств и опровержения, сравнение с соперником
и сохранённый вердикт.

`/pvp_coach` агрегирует последние оценённые матчи текущего сезона, показывает средние
навыки, результат, динамику и главный фокус тренировки. Новая оценка текста не
запрашивается: coaching-layer читает уже сохранённые результаты PvP-судьи.

Чужой матч нельзя открыть подбором `match_id`. Сдачи и тайм-ауты без структурированных
оценок не включаются.

## 🎯 Рейтинговый matchmaking

```text
/ranked_queue Искусственный интеллект полезен обществу
/queue_status
/leave_queue
```

Начальный диапазон по умолчанию составляет `±100 Elo`. Каждые пять минут он
расширяется на `50 Elo`, но не превышает `±400 Elo`.

Подбор учитывает режим, сезон, blocklist, калибровку и Elo. Среди подходящих игроков
выбирается минимальная разница Elo, затем время ожидания и Telegram user ID. Обычная
`/queue` изолирована от рейтинговой и сохраняет first-waiting-first поведение.

## 🏆 Рейтинговые лиги

Первые пять завершённых PvP-матчей считаются калибровочными. Elo изменяется сразу,
но дивизион показывается после окончания калибровки.

| Дивизион | Минимальный Elo |
|---|---:|
| 🥉 Бронза | 0 |
| 🥈 Серебро | 900 |
| 🥇 Золото | 1000 |
| 💠 Платина | 1100 |
| 💎 Алмаз | 1200 |
| 🏅 Мастер | 1300 |
| 👑 Грандмастер | 1450 |

```text
/league               дивизион, место, форма и прогресс
/league_top           топ-10 текущего сезона
/league_distribution  распределение игроков по лигам
```

Лиги вычисляются из существующих агрегатов Elo и отдельно не сохраняются.

## 🎯 Персональные PvP-вызовы

```text
/challenge тема                         reply на сообщение соперника
/challenge 123456789 тема               вызвать известного пользователя
/challenges                             входящие и исходящие вызовы
/accept_challenge a1b2c3d4e5f6          принять вызов
/decline_challenge a1b2c3d4e5f6         отклонить вызов
/cancel_challenge a1b2c3d4e5f6          отменить свой вызов
```

Вызовы хранятся в PostgreSQL, переживают перезапуск и используют состояние
`accepting`, защищающее от двойного запуска матча.

## 🎁 Прогресс и косметика

```text
/daily        ежедневные PvP-задания
/daily_claim  получить завершённые награды
/season       токены, очки, уровень и серии
/season_top   лидерборд сезонного прогресса
/shop         каталог косметики
/buy ID       купить предмет
/inventory    инвентарь
/equip ID     экипировать предмет
/unequip SLOT снять предмет
```

Косметика не влияет на Elo, matchmaking, судейство или результат матча.

## 🛡 Безопасность

```text
/block [user_id]      заблокировать игрока
/unblock user_id      удалить из blocklist
/blocked              показать blocklist
/report ...           пожаловаться на матч
/my_reports           мои жалобы
```

Blocklist применяется к приглашениям, обеим очередям, рематчам, персональным
вызовам и просмотру чужого профиля. Redis user-locks не позволяют одному игроку
оказаться в двух матчах одновременно.

## 🧠 Надёжность season archive

- личная карьера читает только строки и матчи запрашивающего пользователя;
- пик Elo восстанавливается из `rating_before` и `rating_after`;
- архивная таблица использует те же tie-breakers, что live leaderboard;
- сезоны упорядочиваются по последней активности;
- неизвестные и слишком длинные season ID безопасно отклоняются;
- размер каталогов и таблиц ограничен;
- архив не дублирует данные и не может рассинхронизироваться с Elo;
- никаких новых OpenAI-запросов, фоновых задач или runtime-зависимостей нет.

## 🗄️ Хранилища

### PostgreSQL

Профили, архивы одиночных споров, сезонные строки Elo, завершённые PvP-матчи и
судейские оценки, blocklist, жалобы, progression, daily claims, косметика,
публичность профиля и персональные вызовы. Карьера и сезонный архив вычисляются из
этих строк и отдельно не сохраняются.

### Redis

Активные споры и матчи, быстрые приглашения, обычная и рейтинговая очередь,
временные Elo-снимки очереди, дедлайны, request locks и rate limit.

## ⚙️ Настройки PvP

```env
PVP_COACH_WINDOW_MATCHES=10
PVP_RANKED_BASE_ELO_GAP=100
PVP_RANKED_ELO_GAP_STEP=50
PVP_RANKED_EXPAND_INTERVAL_SECONDS=300
PVP_RANKED_MAX_ELO_GAP=400
PVP_CHALLENGE_TTL_HOURS=24
```

Coaching window принимает значения `1..50`. Максимальный ranked Elo-диапазон не
может быть меньше начального.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/DisputesBot.git
cd DisputesBot
cp .env.example .env
```

Заполните `BOT_TOKEN`, `OPENAI_API_KEY` и при необходимости `MODERATOR_USER_IDS`.

```bash
docker compose up -d postgres redis
pip install -e ".[dev]"
alembic upgrade head
python -m bot.main
```

Полный Docker-запуск:

```bash
docker compose up --build -d
```

## 🔐 Приватность

`/pvp_career` показывает пользователю только его собственную карьеру. Исторические
таблицы и Hall of Fame используют те же публичные агрегаты, что текущий PvP-лидерборд,
и не раскрывают аргументы, стенограммы или судейские баллы.

Coaching-отчёты не сохраняются отдельно и доступны только участнику анализируемых
матчей. Рейтинговая очередь хранит временные данные только до подбора, выхода или TTL.

`/delete_me` удаляет профиль, архивы, PvP-рейтинг, матчи и оценки, blocklist,
progression, косметику, публичность, вызовы, активные Redis-сессии и обе очереди.
После удаления исходных строк пользователь исчезает из карьеры и сезонных таблиц.
Жалобы остаются обезличенными аудиторскими записями.
