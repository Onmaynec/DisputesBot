# ⚔️ DisputesBot

**Telegram-бот для тренировки дебатов, логики и аргументации**

Бот всегда занимает противоположную позицию, отвечает по одному аргументу за раз, разбирает сильные и слабые стороны и проводит турнир из трёх раундов.

## ✨ Возможности

- ⚔️ `/debate [тема]` — обычный спор с противоположной позицией бота.
- 🎭 `/role [роль]` — стили **философа**, **юриста**, **шутника** и **циника**.
- 🧠 Один логичный контраргумент за сообщение: тезис, объяснение и пример.
- 📊 После каждых пяти аргументов пользователя — разбор сильных сторон и слабых мест.
- 📝 `/summary` — краткое резюме основных тезисов обеих сторон.
- ⚖️ `/judge` — выбор победителя по качеству аргументации.
- 🏆 `/tournament` — три случайные темы, три раунда, по три аргумента каждой стороны.
- 🧭 Обратная связь после каждого турнирного раунда.
- 🎯 Финальные баллы за логику, аргументацию и креативность — по 10 баллов.
- 🥇 `/leaderboard` — JSON-таблица лидеров по Telegram username.
- 🐳 Docker и GitHub Actions из коробки.

## 🎮 Как проходит спор

```text
/debate Удалённая работа лучше офисной
→ Бот просит выбрать позицию
за
→ Бот занимает позицию «против» и даёт один аргумент
→ Пользователь отвечает
→ Бот даёт один новый контраргумент и ждёт следующий ход
```

История активного спора хранится в `dict` в оперативной памяти. После перезапуска процесса обычные сессии сбрасываются. Турнирные результаты сохраняются отдельно в `data/leaderboard.json`.

## 🏆 Правила турнира

1. Команда `/tournament` показывает три случайные темы.
2. Пользователь выбирает тему кнопкой и указывает позицию: «за» или «против».
3. Турнир включает три раунда:
   - **Раунд 1:** определения и базовая логика;
   - **Раунд 2:** факты, примеры и контрпримеры;
   - **Раунд 3:** последствия, компромиссы и итоговый синтез.
4. В каждом раунде пользователь и бот дают по три аргумента.
5. После раунда бот даёт персональную обратную связь.
6. Финальная оценка: **логика /10**, **аргументация /10**, **креативность /10**.
7. Лучший и средний результаты записываются в JSON-лидерборд.

## 🚀 Быстрый запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Onmaynec/DisputesBot.git
cd DisputesBot
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

Для разработки:

```bash
pip install -e ".[dev]"
```

### 4. Настройте переменные окружения

```bash
cp .env.example .env
```

Заполните `.env`:

```dotenv
BOT_TOKEN=токен_от_BotFather
OPENAI_API_KEY=ваш_api_ключ
OPENAI_MODEL=gpt-5.5
LEADERBOARD_PATH=data/leaderboard.json
LOG_LEVEL=INFO
```

> Модель в `OPENAI_MODEL` должна быть доступна в вашем API-проекте. Секреты не следует добавлять в Git — файл `.env` уже включён в `.gitignore`.

### 5. Запустите бота

```bash
python -m bot.main
```

## 🐳 Запуск через Docker

```bash
cp .env.example .env
# заполните .env
docker compose up -d --build
```

Каталог `./data` подключается как volume, поэтому лидерборд сохраняется при пересоздании контейнера.

| `/start` | Приветствие и инструкция |

| `/leaderboard` | Топ-10 результатов |

## 🔐 Безопасность и ограничения

- Не публикуйте `BOT_TOKEN` и `OPENAI_API_KEY`.
- История спора передаётся модели для генерации следующего ответа, резюме и оценки.
- Активные сессии хранятся только в памяти одного процесса. Для нескольких реплик приложения замените `MemoryStore` на Redis или базу данных.
- JSON подходит для небольшого проекта. При высокой нагрузке лучше использовать PostgreSQL.
- Бот тренирует аргументацию и не заменяет профессиональную юридическую, медицинскую или финансовую консультацию.
