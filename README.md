## 🎯 Рейтинговый matchmaking

```text
/ranked_queue Искусственный интеллект полезен обществу
/queue_status
/leave_queue
```

При входе бот фиксирует текущий Elo и число завершённых матчей. Начальный диапазон
по умолчанию составляет `±100 Elo`. Каждые пять минут он расширяется на `50 Elo`,
но не превышает `±400 Elo`.

Подбор работает детерминированно:

1. режимы очереди и сезоны должны совпадать;
2. blocklist проверяется в обе стороны;
3. калибровочный игрок не смешивается с игроком, уже получившим дивизион;
4. разница Elo должна входить в текущее расширенное окно;
5. выбирается минимальная разница Elo;
6. при равенстве учитываются время ожидания и Telegram user ID.

Обычная `/queue` продолжает работать отдельно и выбирает самого давно ожидающего
подходящего участника. Обе очереди запускают существующий проверенный PvP-движок,
используют те же Redis user-locks и подчиняются anti-farming правилам Elo.

### Настройки

```env
PVP_RANKED_BASE_ELO_GAP=100
PVP_RANKED_ELO_GAP_STEP=50
PVP_RANKED_EXPAND_INTERVAL_SECONDS=300
PVP_RANKED_MAX_ELO_GAP=400
```

Максимальный диапазон не может быть меньше начального. Все значения должны быть
положительными.

## 🏆 Рейтинговые лиги

Первые пять завершённых PvP-матчей считаются калибровочными. Elo изменяется сразу,
но дивизион показывается после окончания калибровки.

| Дивизион | Минимальный Elo |
|---|---:|
| 🥉 Бронза | 0 |
| 🥈 Серебро | 900 |
| 🥇 Золото | 1000 |
| 💠 Платина | 1100 |
| 💎 Алмаз | 1200 |
| 🏅 Мастер | 1300 |
| 👑 Грандмастер | 1450 |

```text
/league               дивизион, место, форма и прогресс
/league_top           топ-10 сезона с дивизионами
/league_distribution  распределение игроков по лигам
```

Лиги вычисляются из существующих агрегатов Elo и не сохраняются отдельно.

## 🎯 Персональные PvP-вызовы

```text
/challenge тема                         reply на сообщение соперника
/challenge 123456789 тема               вызвать известного пользователя
/challenges                             входящие и исходящие вызовы
/accept_challenge a1b2c3d4e5f6          принять вызов
/decline_challenge a1b2c3d4e5f6         отклонить вызов
/cancel_challenge a1b2c3d4e5f6          отменить свой вызов
```

Вызовы хранятся в PostgreSQL, переживают перезапуск и используют промежуточное
состояние `accepting`, защищающее от двойного запуска матча.

```text

/season       токены, очки, уровень и серии
```

Косметика не влияет на Elo, matchmaking, судейство или результат матча.

## 🛡 Безопасность

```text
/block [user_id]      заблокировать игрока
/unblock user_id      удалить из blocklist
/blocked              показать blocklist
/report ...           пожаловаться на матч
/my_reports           мои жалобы
```

Blocklist применяется к приглашениям, обеим очередям, рематчам, персональным
вызовам и просмотру чужого профиля. Redis user-locks не позволяют одному игроку
оказаться в двух матчах одновременно.

## 🧠 Надёжность v0.12

- старые queue payload без новых полей читаются как `mode=open`;
- один пользователь имеет не более одной актуальной записи очереди;
- истёкшие записи удаляются при следующем matchmaking-запросе;
- занятые пользователи удаляются из очереди;
- неподходящие по режиму, сезону, Elo или blocklist записи сохраняются;
- при ошибке создания матча оба участника возвращаются в очередь;
- диапазон поиска вычисляется из enqueue timestamp и конфигурации;
- ranked metadata хранится только временно в Redis;
- новых runtime-зависимостей и фоновых задач нет.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/DisputesBot.git
cd DisputesBot
cp .env.example .env
```

Заполните `BOT_TOKEN`, `OPENAI_API_KEY` и при необходимости `MODERATOR_USER_IDS`.

```bash
docker compose up -d postgres redis
pip install -e ".[dev]"
alembic upgrade head
python -m bot.main
```

Полный Docker-запуск:

```bash
docker compose up --build -d
```

## 🔐 Приватность

Рейтинговая очередь временно хранит в Redis Telegram user ID, отображаемое имя,
username, тему, режим, Elo-снимок, число завершённых матчей и время входа. Данные
исчезают при подборе, выходе, удалении аккаунта или истечении queue TTL.

`/delete_me` удаляет профиль, архивы, PvP-рейтинг, матчи, blocklist, progression,
косметику, публичность, персональные вызовы, активные Redis-сессии и обе очереди.
Жалобы остаются обезличенными аудиторскими записями.
