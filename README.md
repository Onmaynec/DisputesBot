## 🏆 Рейтинговые лиги

Первые пять завершённых PvP-матчей считаются калибровочными. Elo продолжает
изменяться обычным образом, но дивизион показывается только после завершения
калибровки.

| Дивизион | Минимальный Elo |
|---|---:|
| 🥉 Бронза | 0 |
| 🥈 Серебро | 900 |
| 🥇 Золото | 1000 |
| 💠 Платина | 1100 |
| 💎 Алмаз | 1200 |
| 🏅 Мастер | 1300 |
| 👑 Грандмастер | 1450 |

```text
/league               личный дивизион, место, форма и прогресс
/league_top           топ-10 текущего сезона с дивизионами
/league_distribution  количество и доля игроков в каждой лиге
```

`/league` показывает результаты последних пяти матчей в хронологическом порядке:
`В` — победа, `Н` — ничья, `П` — поражение. Elo-дельта учитывает только рейтинговые
матчи; нерейтинговые игры из anti-farming окна остаются в форме, но не меняют дельту.

Лига — это представление существующего сезонного Elo. Она не влияет на подбор,
судейство, ежедневные задания, награды или расчёт рейтинга.

## ⚔️ Соперники и личные встречи

Социальная статистика строится только по завершённым матчам текущего пользователя.
Чужие матчи и приватные данные не попадают в `/rivals` или `/head_to_head`.

```text
/rivals                     пять самых частых соперников
/head_to_head 123456789      личные встречи с игроком
/head_to_head                можно отправить reply на сообщение игрока
```

`/rivals` сортирует игроков по числу встреч, затем по дате последнего матча и ID.
Для каждого соперника показываются матчи, победы/ничьи/поражения и суммарная
Elo-дельта только по рейтинговым играм.

`/head_to_head` показывает:

- общее и рейтинговое число общих матчей;
- победы, ничьи и поражения;
- суммарное изменение Elo;
- текущую серию побед;
- дату последней встречи;
- три последние темы.

## 🔐 Публичность PvP-профиля

Профиль **приватный по умолчанию**. Собственная карточка всегда доступна владельцу.

```text
/pvp_profile                         своя карточка
/pvp_profile 123456789               чужая публичная карточка
/pvp_profile                         reply на сообщение игрока
/profile_visibility                  текущая настройка
/profile_visibility public           разрешить просмотр
/profile_visibility private          скрыть профиль
```

Публичная карточка содержит Elo, место, сезонную статистику, очки и экипированную
косметику. Баланс токенов показывается только владельцу. Если один пользователь
заблокировал другого, просмотр профиля запрещён независимо от настройки публичности.

## 🛍 PvP-косметика

Токены из ежедневных заданий можно тратить на косметические награды.
Косметика не меняет Elo, подбор соперника, судейство или исход матча.

```text
/shop                 каталог, цены и требования
/buy sharp_mind       купить предмет по item ID
/inventory            показать купленные предметы
/equip sharp_mind     экипировать титул или значок
/unequip title        снять титул
/unequip badge        снять значок
```

Каталог содержит четыре значка и четыре титула. Часть предметов открывается только
после достижения определённого количества сезонных очков. Требование проверяется
на сервере до списания токенов.

### Надёжность покупок

- профиль и progression wallet блокируются внутри одной транзакции;
- повторная покупка того же `item_id` не списывает токены;
- баланс проверяется и изменяется атомарно;
- первый предмет каждого типа автоматически экипируется;
- инвентарь разделён по сезонам;
- loadout хранит не более одного титула и одного значка.

## 🎯 Ежедневные задания

Каждый progression-день бот детерминированно выбирает три задания из каталога:

- завершить один или два PvP-матча;
- победить в PvP;
- завершить два рейтинговых матча;
- сыграть с двумя разными соперниками;
- победить в рейтинговом матче.

```text
/daily        показать задания, прогресс и награды
/daily_claim  получить все завершённые неполученные награды
```

Набор вычисляется по progression-дате и не меняется после перезапуска. Прогресс
читается из неизменяемой истории завершённых матчей. Повторный claim не начисляет
награду второй раз.

## 🏅 Сезонный прогресс

Сезонные очки существуют отдельно от Elo.

| Уровень | Название | Минимум очков |
|---:|---|---:|
| 1 | Новичок | 0 |
| 2 | Спорщик | 100 |
| 3 | Оратор | 250 |
| 4 | Тактик | 450 |
| 5 | Мастер аргумента | 700 |
| 6 | Легенда сезона | 1000 |

```text
/season      токены, очки, уровень и серии
/season_top  топ-10 по очкам текущего сезона
```

## 📊 PvP-аналитика

Команда `/pvp_stats` показывает:

- текущий Elo и место в сезоне;
- рейтинговые и нерейтинговые матчи;
- победы, ничьи, поражения и win rate;
- число уникальных соперников;
- изменение Elo за настраиваемое окно;
- текущую и лучшую серию побед;
- результаты отдельно за стороны «за» и «против».

## 🧠 Надёжность league-layer

- калибровка и дивизион вычисляются детерминированно из `rating` и `games`;
- рейтинг не дублируется в новой таблице и не может рассинхронизироваться;
- ранжирование использует Elo, число матчей, время обновления и user ID;
- форма читается только из неизменяемых завершённых матчей текущего сезона;
- Elo-дельта исключает нерейтинговые матчи;
- league-layer не читает стенограммы, аргументы или оценки судьи;
- новых фоновых задач и OpenAI-запросов нет.

## 🗄️ Хранилища

### PostgreSQL

Постоянно хранятся профили, архивы, PvP Elo, завершённые матчи, blocklist,
жалобы, progression wallets, daily claims, косметический инвентарь, loadout и
настройка публичности PvP-профиля. Лиги отдельно не сохраняются.

### Redis

Временно хранятся активные споры, PvP-матчи, приглашения, очередь, дедлайны,
request locks, rate limit и подтверждение удаления данных.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/DisputesBot.git
cd DisputesBot
cp .env.example .env
```

Заполните `BOT_TOKEN`, `OPENAI_API_KEY` и при необходимости `MODERATOR_USER_IDS`.

```bash
docker compose up -d postgres redis
pip install -e ".[dev]"
alembic upgrade head
python -m bot.main
```

Полный запуск в Docker:

```bash
docker compose up --build -d
```

## ⬆️ Обновление с v0.9

```bash
git pull

```

v0.10 не добавляет таблиц и не изменяет схему. `alembic upgrade head` остаётся

`0006_social_profiles`.

Существующие Elo, матчи, профили, токены, косметика, blocklist и жалобы не
изменяются. Новых runtime-зависимостей нет.

## 🔐 Приватность

`/delete_me` удаляет профиль, архивы, PvP-рейтинг, историю матчей, blocklist,
progression wallet, daily claims, косметический инвентарь, loadout, публичность,
настройки и активные Redis-сессии. Жалобы остаются как обезличенные аудиторские записи.

Лиги не хранят отдельные персональные данные: название дивизиона, прогресс и
распределение вычисляются при запросе из существующих агрегатов Elo и матчей.
