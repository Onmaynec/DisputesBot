## 🎓 Приватный PvP coaching

### Подробный разбор матча

```text
/match_review
/match_review 0123456789abcdef
```

Без аргумента команда выбирает последний полный матч текущего сезона, завершённый
независимым судьёй. С указанным `match_id` можно открыть другой собственный матч.

Разбор показывает:

- тему, позицию, соперника, результат и Elo-дельту;
- баллы по логике, доказательствам и опровержению;
- сравнение каждого критерия с соперником;
- общий счёт из 30 баллов;
- сильнейший навык и навык с минимальной оценкой;
- детерминированную практическую рекомендацию;
- сохранённый вердикт независимого судьи.

Матч нельзя открыть по ID, если пользователь не был его участником. Сдачи и тайм-ауты
без структурированных оценок не используются.

### Общий coaching-отчёт

```text
/pvp_coach
```

Отчёт агрегирует до `PVP_COACH_WINDOW_MATCHES` последних оценённых матчей текущего
сезона и показывает:

- средние баллы по трём навыкам;
- победы, ничьи и поражения в анализируемом окне;
- динамику среднего общего балла;
- сильнейший навык и текущий фокус тренировки;
- средний общий балл отдельно за позиции «за» и «против».

Динамика появляется минимум после четырёх оценённых матчей. Новая оценка текста не
запрашивается: coaching-layer читает уже сохранённые результаты PvP-судьи.

## 🎯 Рейтинговый matchmaking

```text
/ranked_queue Искусственный интеллект полезен обществу
/queue_status
/leave_queue
```

Начальный диапазон по умолчанию составляет `±100 Elo`. Каждые пять минут он
расширяется на `50 Elo`, но не превышает `±400 Elo`.

Подбор учитывает режим, сезон, blocklist, калибровку и Elo. Среди подходящих игроков
выбирается минимальная разница Elo, затем время ожидания и Telegram user ID. Обычная
`/queue` изолирована от рейтинговой и сохраняет first-waiting-first поведение.

## 🏆 Рейтинговые лиги

Первые пять завершённых PvP-матчей считаются калибровочными. Elo изменяется сразу,
но дивизион показывается после окончания калибровки.

| Дивизион | Минимальный Elo |
|---|---:|
| 🥉 Бронза | 0 |
| 🥈 Серебро | 900 |
| 🥇 Золото | 1000 |
| 💠 Платина | 1100 |
| 💎 Алмаз | 1200 |
| 🏅 Мастер | 1300 |
| 👑 Грандмастер | 1450 |

```text
/league               дивизион, место, форма и прогресс
/league_top           топ-10 сезона с дивизионами
/league_distribution  распределение игроков по лигам
```

Лиги вычисляются из существующих агрегатов Elo и отдельно не сохраняются.

## 🎯 Персональные PvP-вызовы

```text
/challenge тема                         reply на сообщение соперника
/challenge 123456789 тема               вызвать известного пользователя
/challenges                             входящие и исходящие вызовы
/accept_challenge a1b2c3d4e5f6          принять вызов
/decline_challenge a1b2c3d4e5f6         отклонить вызов
/cancel_challenge a1b2c3d4e5f6          отменить свой вызов
```

Вызовы хранятся в PostgreSQL, переживают перезапуск и используют состояние
`accepting`, защищающее от двойного запуска матча.

## 🎁 Прогресс и косметика

```text
/daily        ежедневные PvP-задания
/daily_claim  получить завершённые награды
/season       токены, очки, уровень и серии
/season_top   лидерборд сезонного прогресса
/shop         каталог косметики
/buy ID       купить предмет
/inventory    инвентарь
/equip ID     экипировать предмет
/unequip SLOT снять предмет
```

Косметика не влияет на Elo, matchmaking, судейство или результат матча.

## 🛡 Безопасность

```text
/block [user_id]      заблокировать игрока
/unblock user_id      удалить из blocklist
/blocked              показать blocklist
/report ...           пожаловаться на матч
/my_reports           мои жалобы
```

Blocklist применяется к приглашениям, обеим очередям, рематчам, персональным
вызовам и просмотру чужого профиля. Redis user-locks не позволяют одному игроку
оказаться в двух матчах одновременно.

## 🧠 Надёжность coaching-layer

- выбираются только матчи текущего сезона с участием запрашивающего пользователя;
- чужой матч нельзя открыть подбором `match_id`;
- повреждённые или неполные score payload пропускаются;
- сдачи и тайм-ауты без судейских баллов исключаются;
- тренд сравнивает равные по размеру свежую и старую выборки;
- tie-break навыков детерминирован: logic, evidence, rebuttal;
- coaching не меняет Elo, результат, matchmaking или награды;
- отдельный skill-профиль не сохраняется;
- новых runtime-зависимостей и фоновых задач нет.

## 🗄️ Хранилища

### PostgreSQL

Профили, архивы, сезонный Elo, завершённые матчи и судейские оценки, blocklist,
жалобы, progression, daily claims, косметика, публичность профиля и вызовы.

### Redis

Активные споры и матчи, быстрые приглашения, обычная и рейтинговая очередь,
временные Elo-снимки очереди, дедлайны, request locks и rate limit.

## ⚙️ Настройки PvP

```env
PVP_COACH_WINDOW_MATCHES=10
PVP_RANKED_BASE_ELO_GAP=100
PVP_RANKED_ELO_GAP_STEP=50
PVP_RANKED_EXPAND_INTERVAL_SECONDS=300
PVP_RANKED_MAX_ELO_GAP=400
PVP_CHALLENGE_TTL_HOURS=24
```

Coaching window принимает значения `1..50`. Максимальный ranked Elo-диапазон не
может быть меньше начального.

## 🔐 Приватность

Coaching-отчёты не сохраняются отдельно и доступны только участнику анализируемых
матчей. Они вычисляются из судейских оценок, уже входящих в историю завершённой дуэли.
Удаление истории матчей удаляет и источник coaching-аналитики.

Рейтинговая очередь временно хранит в Redis Telegram user ID, отображаемое имя,
username, тему, режим, Elo-снимок, число матчей и время входа. Данные исчезают при
подборе, выходе, удалении аккаунта или истечении queue TTL.

`/delete_me` удаляет профиль, архивы, PvP-рейтинг, матчи и оценки, blocklist,
progression, косметику, публичность, вызовы, активные Redis-сессии и обе очереди.
Жалобы остаются обезличенными аудиторскими записями.
