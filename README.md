## 🛍 PvP-косметика

Токены из ежедневных заданий теперь можно тратить на косметические награды.
Косметика не меняет Elo, подбор соперника, судейство или исход матча.

```text
/shop                 каталог, цены и требования
/buy sharp_mind       купить предмет по item ID
/inventory            показать купленные предметы
/equip sharp_mind     экипировать титул или значок
/unequip title        снять титул
/unequip badge        снять значок
/pvp_profile          показать публичную карточку
```

Каталог содержит четыре значка и четыре титула. Часть предметов открывается только
после достижения определённого количества сезонных очков. Требование проверяется
на сервере до списания токенов.

### Надёжность покупок

- профиль и progression wallet блокируются внутри одной транзакции;
- повторная покупка того же `item_id` не списывает токены;
- баланс проверяется и изменяется атомарно;
- первый предмет каждого типа автоматически экипируется;
- инвентарь разделён по сезонам;
- loadout хранит не более одного титула и одного значка.

## 🎯 Ежедневные задания

Каждый progression-день бот детерминированно выбирает три задания из каталога:

- завершить один или два PvP-матча;
- победить в PvP;
- завершить два рейтинговых матча;
- сыграть с двумя разными соперниками;
- победить в рейтинговом матче.

```text
/daily        показать задания, прогресс и награды
/daily_claim  получить все завершённые неполученные награды
```

Набор вычисляется по progression-дате и не меняется после перезапуска. Прогресс
читается из неизменяемой истории завершённых матчей. Повторный claim не начисляет
награду второй раз.

## 🏅 Сезонный прогресс

Сезонные очки существуют отдельно от Elo.

| Уровень | Название | Минимум очков |
|---:|---|---:|
| 1 | Новичок | 0 |
| 2 | Спорщик | 100 |
| 3 | Оратор | 250 |
| 4 | Тактик | 450 |
| 5 | Мастер аргумента | 700 |
| 6 | Легенда сезона | 1000 |

```text
/season      токены, очки, уровень и серии
/season_top  топ-10 по очкам текущего сезона
```

## 📊 PvP-аналитика

Команда `/pvp_stats` показывает:

- текущий Elo и место в сезоне;
- рейтинговые и нерейтинговые матчи;
- победы, ничьи, поражения и win rate;
- число уникальных соперников;
- изменение Elo за настраиваемое окно;
- текущую и лучшую серию побед;
- результаты отдельно за стороны «за» и «против».

## 🗄️ Хранилища

### PostgreSQL

Постоянно хранятся профили, архивы, PvP Elo, завершённые матчи, blocklist,
жалобы, progression wallets, daily claims, сезонный косметический инвентарь и loadout.

### Redis

Временно хранятся активные споры, PvP-матчи, приглашения, очередь, дедлайны,
request locks, rate limit и подтверждение удаления данных.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/DisputesBot.git
cd DisputesBot
cp .env.example .env
```

Заполните `BOT_TOKEN`, `OPENAI_API_KEY` и при необходимости `MODERATOR_USER_IDS`.

```bash
docker compose up -d postgres redis
pip install -e ".[dev]"
alembic upgrade head
python -m bot.main
```

Полный запуск в Docker:

```bash
docker compose up --build -d
```

## 🔐 Приватность

`/delete_me` удаляет профиль, архивы, PvP-рейтинг, историю матчей, blocklist,
progression wallet, daily claims, косметический инвентарь, loadout, настройки и
активные Redis-сессии. Жалобы остаются как обезличенные аудиторские записи.

Косметика хранит только catalog item ID, сезон и время покупки. Тексты дебатов,
аргументы и данные соперников в инвентаре не сохраняются.
